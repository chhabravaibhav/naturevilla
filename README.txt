  Nature Villa AI Concierge — Setup Guide
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

REQUIREMENTS
  • Node.js installed (free: https://nodejs.org)
  • Your Anthropic API key (https://console.anthropic.com)

HOW TO RUN
  1. Open Terminal (Mac) or Command Prompt (Windows)
  2. Navigate to this folder:
       cd path/to/villa-concierge
  3. Start the server with your API key:
       node server.js sk-ant-api03-YOUR-KEY-HERE
  4. Open your browser and go to:
       http://localhost:3000

That's it! The concierge will be live and working.

TO STOP THE SERVER
  Press Ctrl+C in the terminal window.

CUSTOMISING
  Edit index.html → find the SYS variable near the bottom
  to update villa details, WiFi password, house rules, etc.
